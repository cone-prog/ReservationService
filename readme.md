# ReservationService

Backend-сервис для бронирования рабочих мест в коворкинге.

## Возможности

- получение списка рабочих мест;
- просмотр доступных слотов;
- создание, подтверждение и отмена бронирований;
- автоматическое истечение неподтверждённых бронирований;
- защита от конкурентного бронирования одного слота;
- unit- и integration-тесты.

## Технологии

- .NET 10
- ASP.NET Core Minimal API
- Carter
- PostgreSQL
- Dapper
- FluentValidation
- Mapster
- Docker
- xUnit / Moq
- Testcontainers

## Конкурентность

Для защиты от одновременного бронирования одного временного интервала используются транзакции и PostgreSQL `EXCLUDE` constraint.
